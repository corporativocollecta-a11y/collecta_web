Guía rápida

Cómo leer este mapa

  1. Elige un producto en la lista de la izquierda. Puedes buscarlo o filtrar frutas, hortalizas y granos.
  2. Lee el mapa. El color de cada estado dice si su producción alcanza para su población (naranja: le falta; verde: le sobra). Activa Volumen para ver cuánto produce, o cambia a Municipios para ver 2,475 municipios.
  3. Haz clic en un estado o municipio para ver quién lo abastece, a dónde envía su excedente y qué produce.
  4. Usa el Simulador para probar sequías, rutas directas o menos intermediación, y ver el efecto en el precio.
